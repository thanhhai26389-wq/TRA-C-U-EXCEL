# Tra cứu suất ăn sẵn

Trang tra cứu: https://thanhhai26389-wq.github.io/TRA-C-U-EXCEL/

Tải file hoặc sao chép toàn bộ mã HTML: https://thanhhai26389-wq.github.io/TRA-C-U-EXCEL/ma-html.html

Trên iPhone, mở đường link trong Safari. Nhập tên, địa chỉ, mã hoặc số hợp đồng; chọn loại hình hoạt động, bấm **Tra cứu**, rồi bấm tên đơn vị trong kết quả. Phím Enter cũng thực hiện tra cứu. Greatfood thuộc loại **Cung cấp suất ăn**.

## Dữ liệu và hiển thị

- Dữ liệu được tổng hợp từ 4 Excel anh cung cấp. Bản hiện tại chưa đồng bộ Google Sheets.
- Đơn vị trọng tâm màu đỏ; đơn vị cung cấp màu xanh lá; đơn vị nhận cung cấp màu xanh dương. Bấm nhóm để mở danh sách liên quan; thông tin giấy tờ hiện trực tiếp.
- Thanh Đa: tổng 2.000 suất theo cập nhật của anh. Hạnh Phúc: chờ danh sách chi tiết 7 nơi nhận; không lấy danh sách của Xích Long để thay thế.
- Các ô chưa có dữ liệu ghi “Chưa cập nhật”. Thông tin giấy tờ theo kê khai, chưa được xác minh độc lập. Tên trùng được giữ theo hồ sơ nguồn, không tự gộp.
- HTML chứa dữ liệu tra cứu nhưng không đính kèm các file Excel gốc. Bản đồ mở qua Google Maps và cần Internet.
- Khi mã tìm kiếm bị chặn, các hồ sơ HTML có sẵn vẫn đọc được bằng cách bấm nhóm và tên. Để dùng ô tìm kiếm, mở website trong trình duyệt.

## Cập nhật website

GitHub Pages xuất bản từ nhánh `gh-pages`, thư mục gốc `/`. Đưa bản `index.html` đã kiểm tra vào nhánh `gh-pages`, sao chép cùng bản đó thành `tra-cuu-moi.html` và đẩy lên GitHub để xuất bản phiên bản mới. `ma-html.html` cung cấp nút tải file và sao chép nguyên mã; `.nojekyll` tắt xử lý Jekyll. Chỉ sửa nhánh `main` sẽ chưa cập nhật website.

## Kiểm tra

Đã kiểm tra tra cứu, bộ lọc, nhóm liên quan, dữ liệu Thanh Đa/Hạnh Phúc và bố cục 390 px bằng Chromium, gồm trường hợp JavaScript chạy, bị tắt hoặc bị chặn. Chưa kiểm tra trực tiếp trên thiết bị iPhone.

Lưu bằng Notepad trên máy tính
  1. Bấm Sao chép toàn bộ mã, mở Notepad và dán vào.
  2. Chọn File → Save As, đặt tên tra-cuu-moi.html.
  3. Chọn Save as type: All Files (*.*) và Encoding: UTF-8, rồi lưu.
  4. Mở file vừa lưu bằng trình duyệt để tra cứu. Dữ liệu đã nằm trong file; Google Maps cần Internet.

Trên iPhone, anh mở bản tra cứu trên website bằng Safari để dùng ô tìm kiếm. Nếu tải file để lưu, chọn Tải xuống hoặc Chia sẻ → Lưu vào Tệp tùy màn hình Safari.
